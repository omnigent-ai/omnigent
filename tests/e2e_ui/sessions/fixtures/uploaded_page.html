Omnigent User Study Script Draft

Internal draft for a moderated usability session (45 minutes).

Warm-up

  1. Tell us about the last time you used an AI coding assistant.
  2. Which tools do you use most often, and why?

Tasks

  1. Start a new session and ask the agent to summarize a file you upload.
  2. Rename the session so you can find it later.
  3. Share the session with a teammate.

Wrap-up

What was confusing? What would you change first?
