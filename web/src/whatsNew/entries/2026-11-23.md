# Shared projects and a smoother review flow

- **Share a project with teammates.** Project owners can invite other people to a project, and shared members can file changes that go through the same review flow as everyone else's.
- **Reviews now land themselves.** Once the Reviewer approves a change, it lands, the app rebuilds and the server restarts automatically, so approved work reaches you sooner.
- **Questions reach the right person.** Tickets that need a human answer now show up for the people who have to answer them, instead of waiting on the owner.
- **Copy a link to any ticket or project.** A Copy URL button sits in the ticket header and in a project's Sharing settings.
- **See what's new on the board.** Project folders in the sidebar show a badge when tickets were added since you last opened the board.
- **Screenshots show inline on tickets,** so evidence is visible without downloading files.
